# ⚖️ Exam Composition, Point Balancing & Timing Guidelines

To accurately simulate university-level written exams (e.g. TUM, ETH, MIT), follow these composition constraints:

---

## 1. Exam Structure & Point Allocation

- **Standard Point Scale:** 100 to 120 Total Points (typically ~1.0 to 1.3 points per minute).
- **Overhead / Buffer Points:** Include 5–10% buffer points (e.g. 120 points for a 100-point 1.0 grade threshold) to mirror official European university exam designs.
- **Equal Weighting:** If there are $N$ lecture modules, distribute points evenly across modules ($120 / N$ pts each).

---

## 2. Format Distribution Guidelines

Every generated exam paper must adhere to this balanced mix:

| Question Format Archetype | Target Percentage | Primary Cognitive Depth |
| :--- | :---: | :--- |
| **Applied Scenario Analysis** | **25% – 30%** | Bloom L3 (Apply) / L4 (Evaluate) |
| **Taxonomy & Definition Recall** | **20% – 25%** | Bloom L1 (Remember) / L2 (Understand) |
| **Comparative Matrices & Tables** | **15% – 20%** | Bloom L2 (Understand) / L3 (Apply) |
| **Numerical & Metric Calculations** | **15% – 20%** | Bloom L3 (Apply) |
| **Forensic Error-Spotting / True-False** | **10% – 15%** | Bloom L4 (Evaluate) |
