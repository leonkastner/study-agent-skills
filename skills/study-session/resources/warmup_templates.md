# ⚡ 2-Minute Spiral Warmup Question Generator Templates

Every study session opens with 1–2 rapid-fire warmup questions to activate memory pathways and counteract knowledge decay.

---

## Warmup Archetypes

### Archetype A: Rapid True/False Verification (4 Statements)
```markdown
⚡ **2-Minute Spiral Warmup (Module X Decay Target):**
Determine if the following 4 statements are **True (T)** or **False (F)**:
1. [Statement 1: Tests a subtle definition boundary]
2. [Statement 2: Tests a common misconception]
3. [Statement 3: Tests a technical constraint]
4. [Statement 4: Tests a regulatory / taxonomy classification]
```

### Archetype B: Fast Listing / Recall (Under 30 Seconds)
```markdown
⚡ **2-Minute Spiral Warmup:**
Name the [N] core components / levels of [Concept] in exact professorial terms. (Bullet points only).
```

### Archetype C: Rapid Formula Recall & Metric Bound
```markdown
⚡ **2-Minute Spiral Warmup:**
State the mathematical formula for [Metric, e.g. Disparate Impact Ratio or Risk Corridor] and define the regulatory acceptance threshold.
```
